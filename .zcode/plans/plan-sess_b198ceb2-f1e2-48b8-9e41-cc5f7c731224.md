## Goal
Make the OIE a fully autonomous paper engine: it already opens CSPs and books profit-side closes; it must now also **manage CCs** (close/roll/assign) and run a **self-contained paper wheel** (CSP-assign → shares → CC → assign → CSP) using its own DB as the share source of truth, with the three-tool split documented (oie = paper, portfolio = live, screener = watchlist).

Three decisions locked with you: (1) CC management = **roll up-and-out first, assignment as fallback**; (2) share source = **paper book self-contained**; (3) keep the name **screener**.

---

## Workstream A — New single decision core (`src/analysis/exit_management.py`)

The engine currently re-derives the close/stop decision inline (`oie_engine.py:400–465`) with **hardcoded** thresholds and **zero test coverage**. Extract it into a pure, testable function so the CC fix is provable.

New function:
```python
def decide_exit_action(strategy, profit_captured, dte, delta, pnl_dollars,
                       trend_ctx, capital_scarcity, csp_paused, cfg=None
                       ) -> ExitDecision
```
Returns `(close_reason, roll_decision)` where `close_reason ∈ {None, EXPIRE, CC_ASSIGN, CSP_ASSIGN, STOP_DELTA, STOP_LOSS, CLOSE_50PCT, CLOSE_TREND}` and `roll_decision ∈ {None, ROLL_UP_OUT, ROLL_DOWN_OUT}`.

It composes:
1. **Profit side** — delegate to existing `decide_profit_target()` (unchanged). Maps `ACTION_CLOSE`→CLOSE_50PCT/CLOSE_TREND, `ACTION_ROLL_*`→roll_decision, `ACTION_MANAGE_DTE`→falls through to stop/expiry tiers (the bug today: it dead-ends for CC).
2. **Loss side — delta gates, now config-driven and symmetric**:
   - CSP `|Δ| ≥ cfg.stop_delta_csp_critical` (0.60) → `STOP_DELTA` (unchanged behavior).
   - **CC `Δ ≥ cfg.stop_delta_cc_close` (new, 0.60) → `ROLL_UP_OUT`** (the core fix). Reuses the existing roll block (`oie_engine.py:510–521`) which closes the leg; Phase 4 screen then reopens a higher-strike CC via the normal delta band. If screen finds nothing, shares sit unencumbered = correct fallback.
3. **Loss side — premium tiers**: DTE-adjusted (`>30: 3×`, `21–30: 2×`, `≤21: 1.5×`) read from `cfg.stop_loss('premium_stop', …)` instead of hardcoded. Applies to both CC and CSP.
4. **Catch-all** `pnl_dollars < -1000` → `STOP_LOSS`.
5. **DTE≤0 expiry** (ITM/OTM → assign/expire) — kept inline in the engine since it needs `stock_prices`; the pure function returns a sentinel.

This module owns **both** profit and loss exits = the "single decision core" the architecture currently lacks.

1. **Replace inline block `:400–465`** with a call to `decide_exit_action(...)`. Removes all hardcoded thresholds (0.60/0.50/3.0/2.0/1.5/−1000) — enforces the "config is single source of truth" rule in CLAUDE.md.

3. **Self-contained share source**: replace `has_shares = short in self._real_portfolio and …` (`:853`) and the CC gate (`:911`) with:
   ```python
   committed = {o['ticker']: committed.get(t,0)+abs(o['qty'])*100
                for o in self.db.get_active_options() if o['pos_type']=='CALL'}
   free_shares = self.db.get_shares(short) - committed.get(short, 0)
   has_shares = free_shares >= 100
   ```
   This makes the wheel rotate in paper (CSP-assign adds shares via `assign_position('CSP')`; CC-assign removes them). `self._real_portfolio` stays only for pricing/NLV context, not CC gating.
4. **Guard `assign_position('CC')`** (`oie_db.py:277–311`): add a shares-exist check so an auto-assign never silently over-deducts (returns the realized P&L either way; logs a warning if short).
