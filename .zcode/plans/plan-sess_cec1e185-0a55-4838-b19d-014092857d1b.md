## Put Credit Spread (PCS) — Screener + Portfolio Suggestion Layer

Relaxes the blanket "no spreads" ban into a **defined-risk, cash-backed, suggestion-only** income supplement. No auto-execution, no DB persistence, no margin. Aligns with GOAL.md #4 ("never prefer margin") and "paper-trade before live."

### Core strategy logic — *when PCS vs plain CSP*
The screener screens **both** CSP and PCS for every eligible ticker and ranks them together (user chose "always show both, ranked"). Same ticker-level score for both; the contract penalty differentiates. PCS is the right bet when:
- CSP is **paused** (VIX>25 / cash<20% / VOLATILE+ regime / stock >15% off basis), OR
- you want the **directional/IV thesis but NOT the shares** (PCS = no assignment beyond the long leg), OR
- the **strike is too large to fully cash-secure** with available cash.
Plain CSP still wins when you *want* the shares at a good basis (wheel entry) and CSP is allowed.

### Files to create

**1. `src/strategies/__init__.py`** — new package (empty marker).

**2. `src/strategies/credit_spread.py`** — pure, deterministic, no network:
- `put_spread_roc(net_credit, width, dte)` → annualized RoC on `max_loss = width − net_credit`.
- `_spread_penalty(short_leg, long_leg, net_credit, width, cfg)` → spread-specific penalties (mirror `_contract_penalty`'s structure): short-leg DTE/OI/spread/volume via reuse; **credit_ratio penalty** if `net_credit/width < 1/3`; **width-cap** block if `width > max_width`; long-leg liquidity gate.
- `score_put_credit_spreads(puts, snap, ticker_score, regime, cfg, net_liq, cash, ...)` → buckets puts by `expiry`, pairs each eligible short leg (passes `passes_all_gates(...,'CSP',...)` reusing existing filters) with the best long leg within allowed widths, returns `list[TradeCandidate]` with `strategy='PS'`. One best spread per (ticker, expiry) to bound output. Applies the same GEX caution as CSP.
